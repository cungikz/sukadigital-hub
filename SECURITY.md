# Security Policy

Aplikasi ini hanya **prototype demonstrasi** tanpa autentikasi dan tanpa backend. Jangan menggunakannya untuk memproses data pribadi, informasi internal pemerintah, insiden aktual, atau informasi teknis yang sensitif.

Untuk melaporkan kerentanan di proyek open-source ini, hubungi pemelihara repository secara privat apabila kanal tersedia, **jangan unggah eksploitasi, kredensial, atau data sensitif ke GitHub Issues**. Jika kelak digunakan secara nyata, implementasikan perlindungan data, pengujian keamanan, pengelolaan akses, dan prosedur respons insiden yang sesuai sebelum produksi.

Kebijakan ini **tidak** berlaku untuk sistem resmi pemerintah mana pun. Gunakan jalur pelaporan resmi pemerintah untuk sistem yang dimilikinya.
